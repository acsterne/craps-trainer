# Audio Files

Download royalty-free audio files and place them here:

- `jazz.mp3` — Smooth jazz loop. Try bensound.com "sunny" or Free Music Archive search "smooth jazz"
- `dice.mp3` — Dice rattle. freesound.org search "dice roll casino"
- `chip.mp3` — Chip clink. freesound.org search "poker chip"
- `win.mp3` — Win chime. freesound.org search "casino win chime"
- `lose.mp3` — Low loss tone. freesound.org search "low thud"
- `seven-out.mp3` — Seven out sound. freesound.org search "casino horn" or low bell

The app works without audio files — Howler.js silently fails if files are missing.
